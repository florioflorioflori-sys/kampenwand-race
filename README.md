# kampenwand-race

Kampenwand Downhill – Mountainbike-Rennen von der Kampenwand nach Aschau.

- `KampenwandRace/` – Unreal-Engine-5-Projekt (C++), Anleitung in [KampenwandRace/README.md](KampenwandRace/README.md)
- `Tools/prepare_ue_data.py` – bereitet die Geodaten für Unreal auf
- `geodata/` – Heightmap, Streckenlinie und Höhenprofil der Kampenwand (Quelle: AWS Terrain Tiles)
