# kampenwand-race
## v15 – lebendige Fahrer und Zuschauer

- Fahrer: Körperfeder über dem Bike, Kurvenlage mit Außenfuß unten, Wiegetritt, Blick in die Kurve, Fuß am Start abstellen, Jubeln im Ziel, flatterndes Trikot
- Tricks in der Luft (T oder F): Tabletop, Whip, Superman, No-Hander, No-Footer; Sturz mit Abflug über den Lenker
- Zuschauer: eigene Statur und Gesichtsform je Person, Hautdetails, Blinzeln, Blick, offener Mund beim Anfeuern
