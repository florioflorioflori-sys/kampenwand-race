# Figuren für die Browser-Vorschau

Quelle: **Universal Base Characters** von Quaternius (https://quaternius.com/packs/universalbasecharacters.html), Lizenz **CC0 1.0** (gemeinfrei, keine Namensnennung nötig).

- `people.glb`: Mann, Frau, fünf Frisuren, Bart und Augenbrauen, nur Geometrie und Skelett. Erzeugt mit `pack_people.mjs` (gltf-transform: Texturen entfernt, Attribute reduziert, quantisiert).
- `*.jpg`: Haut-, Haar- und Augentexturen, auf 1024 bzw. 512 px verkleinert.

`build.py` bettet alles in die HTML-Datei ein.
